# ESP32-C3 墨水屏智能手表

基于 ESP32-C3 与 1.54寸水墨屏。打通 SPI 与 I2C 双总线，驱动 SSD1680 与 DS3231 时钟。

## 🛠️ 硬件采购清单 (BOM)

| 模块 | 型号/规格 | 购买渠道 (参考) | 备注 |
| :--- | :--- | :--- | :--- |
| 主控 | ESP32-C3-Zero | 淘宝：微雪旗舰店 | 核心板 |
| 屏幕 | 1.54寸水墨屏 | 淘宝：中景园电子 | SSD1680 驱动 |
| 时钟 | DS3231 RTC | 拼多多、淘宝 | 带纽扣电池 |
| 供电 | TP4056 + 3.7V锂电 | 拼多多、淘宝 | 充电管理 |
| 升压 | DC-DC 升压模块 | 拼多多、淘宝 | 3.7V 转 5V |
| 交互 | 微动开关 x3 | 淘宝：任意电子店 | 静音按键 |

## 🔌 引脚接线指南
> ⚠️ **警告：接线前必须拔掉 USB 断电！**

### 1. 墨水屏 (SPI通信)
| 屏幕引脚 | ESP32-C3 引脚 | 说明 |
| :--- | :--- | :--- |
| GND | GND | 地线 |
| VCC | 3V3 | 供电（绝对不要接5V） |
| SCL | GPIO4 | 时钟线 |
| SDA | GPIO6 | 数据线 |
| RES | GPIO5 | 复位 |
| DC | GPIO7 | 数据/命令 |
| CS | GPIO20 | 片选（不能接10） |
| BUSY | GPIO3 | 忙状态 |

### 2. DS3231 时钟 (I2C通信)
| 时钟引脚 | ESP32-C3 引脚 |
| :--- | :--- |
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO8 |
| SCL | GPIO9 |

### 3. 静音按键
| 按键 | ESP32-C3 引脚 | 备注 |
| :--- | :--- | :--- |
| 主键 | GPIO0 | 另一端统一接 GND |
| 加键 | GPIO1 | 另一端统一接 GND |
| 减键 | GPIO2 | 另一端统一接 GND |

## 🔋 供电系统接线
| 连接起点 | 连接终点 |
| :--- | :--- |
| 电池红线 | TP4056 的 B+ |
| 电池黑线 | TP4056 的 B- |
| TP4056 OUT+ | 升压模块 IN+ |
| TP4056 OUT- | 升压模块 IN- |
| 升压模块 OUT+ | ESP32 的 5V |
| 升压模块 OUT- | ESP32 的 GND |

*注：升压模块务必短接 A、B 焊盘，将输出改为 5V。*

## ⚠️ 避坑提醒
- **GPIO18 / GPIO19**：USB 数据线，勿碰。
- **GPIO10**：板载蓝灯，会和屏幕抢信号。
- **5V 引脚**：测试阶段空置。
